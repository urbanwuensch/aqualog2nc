If you are interested in the software but don't have your own OPJs / OGWs, use these files


- "single_type_example.opj": An example of EEMs (marine) where several measurements are stored in one OPJ file. They all have identical settings and will be stored in the root of the NetCDF file.
- "two_type_example.opj": An example of a project where two settings were used to measure samples but they are stored within one OPJ file. Consequently, the two types are stored within groups of the NetCDF file.
- .ogw file: Just an example of an OGW file to show that this type of file (commonly used during SampleQ measurements) can be imported just like opj files.
